# 💬 Sistema de Mensagens de Otimismo & Gestão de Contatos (EAD 60+)

Este projeto é uma aplicação de consola desenvolvida em **Java** para o gerenciamento de contatos e geração de mensagens personalizadas de otimismo direcionadas a datas especiais, mensagens casuais e comemorações.

## 🚀 Funcionalidades

- **Gerenciamento de Contatos (Persistência em Arquivo TXT):**
  - **Cadastro de Usuários (RF1):** Registo obrigatorio de nome e telefone salvo persistentemente em ficheiro `cadastro.txt`.
  - **Listagem de Contatos (RF2):** Leitura e exibição formatada de todos os utilizadores cadastrados.
  - **Busca por Nome (RF3):** Pesquisa dinâmica de contatos por correspondência de nome.
- **Gerador de Mensagens:**
  - **Datas Especiais:** Organização de datas comemorativas divididas por trimestres do ano em matrizes multidimensionais.
  - **Mensagens Casuais & Espirituais:** Composição modular de mensagens combinando saudações e frases de reflexão.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java (JDK 8+)
- **Manipulação de Arquivos:** `FileWriter`, `FileReader`, `BufferedReader` (Pacote `java.io`)
- **Estruturas de Dados:** Matrizes bidimensionais e Vetores (`String[][]`, `String[]`)
- **Entrada de Dados:** `java.util.Scanner`
